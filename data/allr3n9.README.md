# allr3n9.txt placeholder

This package does not include a full rank-3 connected loopless matroid-orbit
reference file for n=9.  To use the experimental Delta(3,9) wide-mask engine,
place a validated JSONL file named `allr3n9.txt` in this directory.

The format is the same as `allr3n8.txt`.  The uniform orbit should have an empty
`ineqs` list and `volume_sha = 36`.
